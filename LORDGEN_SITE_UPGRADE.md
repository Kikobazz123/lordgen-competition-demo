# LordGen AI — Site Upgrade Specification

## Objective

Upgrade the existing LordGen AI website from an impressive technical demo into a premium, conversion-focused AI automation consultancy website.

The existing site already has:
- a black/gold identity
- a hero section
- "One engine. Any business."
- an interactive demo
- a workflow/activity area
- a Business Diagnostic Demo
- category/automation recommendations
- workflow selection
- an estimate/documentation section

Preserve these foundations.

## Core Strategic Shift

Current impression:
"Here is a sophisticated AI automation demo."

Target impression:
"LordGen can look at my business, identify what should be automated, show me the system, and help me deploy it."

The website must communicate business outcomes before implementation details.

## Hero

Keep the premium dark/gold look.

Preferred structure:

EYEBROW
AI AUTOMATION FOR REAL BUSINESSES

HEADLINE
AI Automation Built Around Your Business

SUBHEAD
Turn repetitive business operations into intelligent systems that capture, analyze, decide, and execute.

PRIMARY CTA
Run My Business Diagnostic

SECONDARY CTA
See a Live System

Add a restrained animated systems visualization if it can be implemented without hurting performance.

## Trust Strip

Immediately below the hero, use a concise capability strip:

AI Automation
AI Agents
Workflow Engineering
CRM Automation
API Integration
Business Intelligence

Avoid fake statistics.

## Diagnostic Experience

This is the primary conversion feature.

### Input

Let the visitor select or enter:
- business type
- team size (optional)
- biggest operational problem
- current tools (optional)

### Analysis

Show:
- detected bottleneck
- automation opportunity
- recommended workflow
- systems/tools involved
- next action

### Presentation

Use a premium result card:

"Automation Opportunity"

Problem
Current manual or disconnected process.

Recommended system
Trigger → AI analysis → decision → action → follow-up.

Business impact
Explain qualitative benefit unless a real estimate is available.

CTA
"Build This System"

Secondary:
"Talk to LordGen"

## Problem Section

Create a simple section that mirrors common business pain:

Missed leads
Slow follow-up
Repetitive admin
Disconnected tools
Manual reporting
Inconsistent customer response

Then position LordGen as the system layer that connects these pieces.

## LordGen Operating Model

Use four steps:

01 Diagnose
Understand the workflow and bottleneck.

02 Design
Map the best automation and AI architecture.

03 Build
Connect the tools, data, workflows, and agents.

04 Optimize
Monitor performance and improve the system.

## Solutions

Build outcome-driven cards for:

### Lead Automation
Capture, qualify, route, follow up.

### Customer Support
Answer routine questions, escalate edge cases, preserve context.

### CRM Automation
Create/update records, assign leads, trigger follow-up, maintain pipeline hygiene.

### Operations Automation
Turn repetitive internal processes into structured workflows.

### AI Agents
Research, analyze, decide, and take approved actions.

### Reporting & Intelligence
Turn scattered business data into actionable information.

Each card should have:
- short problem statement
- outcome
- sample workflow
- CTA or "See system"

## Live Systems

Keep the current demos.

Upgrade their presentation into:
- Problem
- Trigger
- AI reasoning / decision
- Action
- Result

Use animated connectors where practical.

Make it obvious which demonstrations are prototypes.

## Proof Section

Until LordGen has real client results, use "Example Systems" instead of fake case studies.

Possible structure:

Example System
Nick's Plumbing — Estimate / Lead Follow-up Prototype

Show:
- problem
- workflow
- automation
- generated output
- tools involved

When real client projects exist, replace prototype cards with evidence-backed case studies.

## CTA Strategy

Use one primary CTA consistently:

"Run My Business Diagnostic"

Secondary CTA:
"Talk to LordGen"

Do not use vague CTAs such as "Learn More" for major conversion paths when a more specific action is available.

## WhatsApp / Contact

For the target market, provide an easy human handoff.

Preferred actions:
- Run Diagnostic
- WhatsApp LordGen
- Book Strategy Call

Do not expose phone numbers, tokens, or credentials in source code.

## Navigation

Keep navigation short:

Home
Solutions
Systems
How It Works
About

Primary button:
Run Diagnostic

Use a compact mobile menu.

## Visual Refinement

Use the current LordGen palette.

Improve:
- section spacing
- hierarchy
- button treatments
- card depth
- motion
- responsive behavior
- typography scale
- workflow visuals
- empty/loading/error states.

Avoid:
- excessive gradients
- excessive glassmorphism
- giant animated backgrounds
- random glowing blobs
- template-like SaaS visuals
- inconsistent corner radii
- too many gold elements.

## 21st.dev Benchmark

Use 21st.dev as inspiration for:
- component quality
- interaction polish
- motion restraint
- responsive behavior
- marketing-section composition.

Do not copy proprietary code, layouts, text, or branding.

## Performance

Prefer CSS transforms and opacity for animation.

Avoid:
- large unnecessary libraries
- blocking web fonts
- oversized background media
- repeated client-side renders
- unnecessary hydration.

Keep the hero fast.

## Accessibility

Required:
- keyboard-accessible interactive components
- visible focus states
- semantic headings
- accessible labels
- sufficient contrast
- reduced-motion support
- usable mobile controls.

## SEO

Every key page should have:
- descriptive title
- meta description
- canonical URL where appropriate
- Open Graph metadata
- correct heading hierarchy
- meaningful alt text.

Use language about AI automation, AI agents, workflows, CRM automation, and business process automation naturally. Avoid keyword stuffing.

## Final UX Test

Pretend you are a business owner who knows nothing about n8n.

Within 10 seconds you should be able to answer:
1. What is LordGen?
2. What problem does it solve?
3. What can it automate?
4. What should I click next?

If any answer is unclear, revise the section.
