# DESIGN RESEARCH

Use 21st.dev and up to four high-quality AI/automation/premium SaaS sites as inspiration only.

Study:
- hero composition
- form simplicity
- progressive reveal
- workflow visualization
- typography
- spacing
- motion
- CTA placement
- mobile behavior
- trust presentation

Do not copy source code, text, brand assets, exact layouts or proprietary animation.

Use AITMPL only to identify a small set of relevant Claude Code skills: frontend design, senior frontend, backend/fullstack, webapp testing and security/review. Do not install a pile of unrelated skills.
