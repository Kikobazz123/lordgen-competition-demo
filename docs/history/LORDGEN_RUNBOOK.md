# REBUILD RUNBOOK

1. Create a git checkpoint.
2. Inspect current frontend, API routes, n8n workflows, environment variables and deployment.
3. Research current design patterns.
4. Plan the smallest clean architecture.
5. Rebuild the frontend into the single phased workflow.
6. Refactor backend/n8n to support the exact state machine.
7. Implement approval -> builder dispatch.
8. Implement README/handover delivery.
9. Run lint/typecheck/tests/build/browser QA.
10. Run controlled production end-to-end test.
11. Report what changed, what is live, tests passed and remaining blockers.
