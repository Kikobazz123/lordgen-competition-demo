# LordGen Frontend Skill

Build a premium minimal interface for a live automation workflow.

Principles:
- Progressive disclosure over information density.
- One primary work surface.
- User always knows where they are and what to do next.
- Black/charcoal + restrained gold.
- Editorial/technical premium feel.
- Generous whitespace.
- Strong hierarchy.
- Subtle motion only.

Required transition:
form -> research progress -> results -> approval -> builder progress -> handover.

Do not stack all phases vertically.
Do not use chat UI.
Do not create duplicate dashboards.
Do not use excessive gradients, glassmorphism, glowing blobs or decorative motion.
Support reduced motion, keyboard navigation, visible focus, semantic headings and mobile layouts.

Test at desktop, tablet and mobile with no horizontal overflow.
